# Project Plan

## Business problem
Explore the composition and metadata quality of a Netflix titles catalogue snapshot.

## Analytics questions
1. What is the movie versus TV-show split?
2. How are titles distributed by release year?
3. Which genre and country labels appear most often?
4. Which content ratings are most common?
5. Which fields contain missing values or exact duplicate records?

## Workflow
Business understanding → data collection → data profiling → preprocessing → cleaning → feature engineering → validation → exploratory data analysis → visualization → dashboard → findings.

## Techniques
Missing-value analysis, duplicate handling, string normalization, type conversion, derived columns, category-frequency analysis, time-trend analysis, visualization, dashboarding, and CSV export.

## Limitations
A catalogue snapshot does not contain viewership or audience preferences. Multi-country and multi-genre records can appear in more than one category. Record the dataset source, download date, and license before sharing findings.
