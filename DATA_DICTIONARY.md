# Data Dictionary

| Field | Meaning | Typical use |
|---|---|---|
| show_id | Catalogue identifier | Record identity |
| type | Movie or TV Show | Content mix |
| title | Title name | Search |
| director | Director(s) | Metadata exploration |
| cast | Cast members | Metadata exploration |
| country | Country/countries listed | Geographic distribution |
| date_added | Date added to the dataset | Addition trends |
| release_year | Original release year | Release trends |
| rating | Content rating | Rating distribution |
| duration | Runtime or season count | Duration exploration |
| listed_in | Genre labels | Genre analysis |
| description | Synopsis | Text metadata |

`date_added` is not the same as `release_year`. A title may list multiple countries and multiple genres, so those category counts may overlap.
